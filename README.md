Sunset Platinum is an offline, open-source trophy guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: a checklist with saved progress, export and import, search and filters, a spoiler setting that hides unearned story trophies, a 7-stage roadmap to the platinum, the 13 missable trophies flagged, a Next-up planner, and a guide to each trophy in our own words that cites its sources. It is static files only and works with the network off.

## Run it

```sh
node serve.ts
```
